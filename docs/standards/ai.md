# AI、检索、FAQ 与 MCP 规范

适用LangChain调用、SQLite FTS5、可选Qdrant、索引worker、答疑AI和FastMCP。

|规则|约束|检查|失败判定|
|---|---|---|---|
|AI-01 班级隔离|检索输入的class_id来自已验证会话；关键词SQL和Qdrant过滤都按班限制；工具由授权服务层调用。|双班chunk交换、请求/引用ID重放、工具server跨班ID。|任何跨班命中或工具越权即阻断。|
|AI-02 引用真实|展示引用必须映射本次检索返回的material/chunk/offset；模型不得生成或补造引用。检索证据缺失时明确拒答。|注入模型虚构编号、错偏移、跨班材料，核对链接和正文。|引用无法回查或虚构出处即失败。|
|AI-03 降级|README定义无模型可用本地确定性流式回退；未配置嵌入时keyword可用，vector/hybrid可返回明确503。错误不能伪装模型回答。|禁用配置、停Qdrant/模型、断SSE；检查模式元数据和错误。|无据确定回答、无限重试或错误当成功即失败。|
|AI-04 Prompt|教师可维护班级Prompt/Skill；版本与归属需可追踪，检索文本和MCP输出是不可信输入，工具调用须白名单及安全清洗。|Prompt跨班访问、注入语料、危险工具名、超长/恶意工具响应。|执行检索内容指令、未经授权调工具或无法追踪Prompt版本即失败/登记缺口。|
|AI-05 评测|每个AI变更需覆盖有据、无据、跨班、提示注入、服务故障与引用回查；运行结果按版本记录，不删失败样例。|脱敏固定用例集，报告模型/Prompt/检索配置、命中及引用核验。|未跑标NOT_RUN；跨班/伪引用任一失败不得验收。|
|AI-06 FAQ/索引|FAQ经教师确认；发布/更新/撤销后重建班级汇总材料并入索引队列。SQLite记录索引状态与任务；网络操作在DB事务外。失败/重试不得静默宣称ready；撤销FAQ须保证聚合材料及旧向量最终删除，失败可诊断。|注入Qdrant故障、重复worker任务、FAQ撤销与迟到索引；核对DB FAQ、材料、活跃generation、检索结果。|事实FAQ丢失、重复材料、撤销项仍可检索或失败不留状态即待修复。|
|AI-07 MCP|`mcp-server` Bearer门禁；令牌只在服务器侧；连接/工具清单和调用以班级授权为前提；主机侧白名单校验工具引用，响应作为不可信数据。|无/错Bearer，跨班服务器ID，伪造清单、注入/超长响应。|未授权工具调用或令牌泄漏即失败。|

现有实现细节以`retrieval.py`、`index_worker.py`、`qa_faq_material.py`、`mcp_client.py`及对应views为准；需求优先，任何缺口进入适配基线待修复清单。
