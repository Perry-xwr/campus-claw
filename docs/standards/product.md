# 产品与页面规范

适用Flask/Jinja原生HTML、内联CSS/JavaScript和JSON/SSE交互；不假设React或独立前端构建。

|规则|约束|检查|失败判定|
|---|---|---|---|
|PRD-01 页面和角色|页面由`campusclaw/templates/`渲染，路由由Flask蓝图登记；导航与入口按需求呈现学生/教师权限。|逐路由以四种测试账号及匿名访问，检查模板导航与后端拒绝一致。|孤立入口、错误角色可达或假业务结果即失败。|
|PRD-02 四态|异步检索、SSE、列表和索引状态需区分加载、正常、空、失败；索引pending/failed不能显示为ready。|空数据库、慢响应、断流、索引失败fixture。|错误显示成空结果、无限spinner或假ready即失败。|
|PRD-03 输入与重复|页面提示字段边界；提交期间防连点，网络不确定时避免重复创建；服务端仍负责校验/幂等。Cookie表单包含CSRF。|边界文本、双击、刷新重提、缺CSRF。|仅靠浏览器校验、重复副作用或CSRF遗漏即失败。|
|PRD-04 状态和反馈|问题状态遵业务需求状态机，AI回答不推进状态、不计人类回复。采纳、关闭、撤销等操作显示成功/冲突/失败且能刷新状态。|状态逐边操作并检查服务端及模板。|UI允许非法转移、状态与统计不一致即失败。|
|PRD-05 现有视觉|保留原生模板渐进增强与移动可读；若需求规定尺寸/对比度/键盘操作则逐项验收，不强制新增构建链。|桌面/窄屏走查，键盘访问表单、SSE与错误提示。|主要路径无法操作或错误不可见即失败。|

模板不得承担授权决策；服务端仍需判权。
