# 业务验收场景

全部NOT_RUN；测试编号用T替换SC。fixture：S1/S3为班A学生，S2为班B学生，T1/T2分别为A/B教师；M在A为学生、B为教师。独立测试数据和固定UTC时钟；“分别”条件须逐项执行并记录，不能只选一项。
## SC-Q01-01

需求：FR-Q01；状态NOT_RUN。

- GIVEN：班级成员有效。
- WHEN：输入标题正文→校验→提交→打开详情。
- THEN：创建一个OPEN问题，作者和班级来自可信身份，版本为1。

## SC-Q01-02

需求：FR-Q01；状态NOT_RUN。

- GIVEN：除本子用例刻意改变的身份、资源状态或版本外，其余条件合法；分别准备以下边界/失败条件：空白、标题121或正文10001字符返回400且不创建；相同幂等键重放返回同一ID。
- WHEN：逐项执行对应操作并记录返回及前后数据。
- THEN：空白、标题121或正文10001字符返回400且不创建；相同幂等键重放返回同一ID；失败无未授权或部分写入。

## SC-COM-09

- THEN：旧内容不再作为引用；不复活撤销FAQ；事实数据保留，重试只索引当前发布版本。
