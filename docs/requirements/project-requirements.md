# 班级答疑广场：项目功能说明

版本：0.1；日期：2026-10-28；状态：待小组确认。本文定义完整产品方向；第7课只执行 `2026-10-28-project-skeleton` 骨架变更。

## 1. 定位与用户

班级答疑广场是面向高校课程班级的问答协作平台，服务学生和教师。学生需要统一提问入口、可见的处理进度和可信的参考资料；教师需要共享答疑、待解决问题队列，以及将有效回答沉淀为课程知识的工具。

目前聊天群和私信中的问题分散、重复回答难复用，知识库检索又无法处理所有问题。本项目用“学生提问→检索辅助→必要时转人工→教师采纳→FAQ沉淀→统计反馈”形成闭环。与聊天相比，问题有班级归属、状态和可追踪来源；与单纯AI问答相比，有真实引用、人类确认和明确的失败出口。AI回答不等同教师认可。

## 2. 五个功能模块

|模块|核心功能与角色|主要流程及边界|
|---|---|---|
|班级答疑广场|学生发布问题；本班学生、教师查看列表/详情、回复讨论|登录并选择所属班级→提交标题/正文→生成OPEN问题→成员回复后变ANSWERED。列表分页、按创建时间及ID稳定排序，可筛状态；非法筛选报400，不忽略；关闭后禁止新增回复。|
|AI辅助答疑|问题作者或本班教师请求课程RAG；查看答案和真实证据；显式转人工|服务端核对班级→调用适配层→验证引用→显示“AI辅助，未经教师确认”。无证据不编造答案；断连/超时显示失败及人工入口，不自动转交。重复转交只产生一个队列记录。|
|教师答疑管理|本班教师查看待解决队列、回复、采纳人类回复、关闭问题|队列包含OPEN/ANSWERED，可优先查看已转人工问题；采纳后ACCEPTED；关闭后CLOSED。学生无采纳/关闭权限，教师无跨班权限。并发写入需版本比较，冲突提示刷新，不覆盖先前结果。|
|FAQ知识沉淀|教师将已采纳回答预览、确认并发布为FAQ；修订和撤销|确认后保存问题、回复、班级、教师及版本关联；关系库事务记录索引任务，事务外投递RAG索引。重复沉淀不创建副本；失败可重试；撤销立即在读取侧隐藏，后台清理索引，迟到任务不能复活内容。|
|简单统计面板|本班教师查看待解决数、已解决数和热门列表|按班和明确时间窗统计，显示统计时间。待解决=OPEN/ANSWERED；已解决=有采纳回复（包括之后关闭的）；关闭但未采纳单列，不能冒充已解决。热门按近7天人类回复数降序、问题创建时间/ID降序取前10，AI结果不计回复。|

### 共同规则（本组建议默认值，待确认）

- 一个用户可属于多个班，角色按班配置。匿名访问未来业务接口401；同班功能越权403；跨班与不存在均404，除request ID外错误正文一致。客户端提交的角色、作者或班级归属不能成为授权依据。
- 问题状态为OPEN、ANSWERED、ACCEPTED、CLOSED。只有人类回复使OPEN变ANSWERED；只有教师采纳使ANSWERED变ACCEPTED；教师可关闭任一未关闭状态；CLOSED为终态，不重开、不再回复。AI结果和转人工不改变问题状态。关闭保留采纳关系。
- 标题1–120字符、正文1–10000字符，去首尾空白后校验；纯文本。分页默认20、最大100；排序追加唯一ID。界面具有加载、正常、空、失败四态。
- 写操作声明幂等键；重复同载荷重放原业务结果，不同载荷复用键返回409。修改已有对象用版本比较，冲突409；前端禁用连点不能代替后端幂等。
- FAQ发布必须教师显式确认；AI不能自行将内容变成可信FAQ。索引异步失败不丢失关系库事实；读取引用时复查班级、发布状态及当前版本。
- 统计数量默认近30天创建的问题，按查询时当前状态计算；热门是近7天回复窗口，两者分别标注。统计刷新延迟建议不超过30秒。以上数值不是老师规定。

## 4. 技术方案与RAG复用边界

推荐Go `net/http`后端、React/TypeScript前端、MySQL事实存储；这是小组建议，不是课程指定。精确工具链版本、依赖锁与镜像digest由A在开发前记录并冻结。浏览器通过同源代理访问后端；依赖方向为handler→application→domain/ports，MySQL/RAG adapter实现ports，cmd装配。

旧CampusClaw只作为经验来源，**不修改、不复制其代码或数据库，不假定其部署可用**。未来RAG通过独立服务契约复用；本课 `RAG_MODE=disabled`，不部署Qdrant、不接问答。adapter以后负责授权上下文传递、超时、错误映射及引用校验；服务方必须按可信class_id隔离，而不是相信用户传入班级。引用至少含document_id、chunk_id、版本、班级及可验证来源；只返回一段文本的旧接口不能直接满足可信引用要求。

建议未来调用总超时8秒，无自动重试；无命中显示无证据，失败提供人工入口，不能编造出处。FAQ采用关系库事务+outbox、事务外索引与对账补偿；不得在数据库事务中等待网络调用。具体业务接口在后续change冻结，本轮不扩展数据库细节。
