# 角色、隔离与流程

继承既有四状态；细化建议待小组确认。所有业务测试NOT_RUN。

|操作|本班学生|本班教师|匿名|其他班|
|---|---|---|---|---|
|发布问题|允许|403（首版不提供教师发问）|401|404|
|问题/回复/发布FAQ读取|允许|允许|401|404|
|未关闭问题回复|允许|允许|401|404|
|AI请求/结果、转人工|仅作者|允许|401|404|
|待办/采纳/关闭/FAQ写入和重试/统计|403|允许|401|404|
|编辑删帖/改回复/重开/撤销采纳|首版不提供|首版不提供|无入口|无入口|

角色按班生效；每次核对有效成员关系。认证→班级/资源可见性→功能权限→输入/版本校验。资源必须同时属于指定班与父对象；客户端作者/角色字段不可信。跨班与不存在404正文一致（request ID除外），禁止缓存/引用串班。

## 问题状态转移

|原状态|操作|操作者|结果|
|---|---|---|---|
|无|发布|本班学生|OPEN，版本1|
|OPEN|人类回复|本班成员|ANSWERED，版本+1|
|ANSWERED|人类回复|本班成员|ANSWERED，版本+1|
|ACCEPTED|人类回复|本班成员|保留ACCEPTED及采纳，版本+1|
|ANSWERED|采纳本问题人类回复|本班教师|ACCEPTED，保存回复关联，版本+1|
|ACCEPTED|再采纳同一回复|本班教师|幂等无变化；另一回复409|
|OPEN/ANSWERED/ACCEPTED|关闭|本班教师|CLOSED，保留采纳，版本+1|
|CLOSED|新回复/采纳/关闭/重开|任何人|409；原幂等请求重放可返回原成功|

AI不算人类回复，不改变问题状态。关闭未采纳不算解决。首版不支持更换采纳或重开，避免增加撤销连锁规则。

## AI转人工
作者/教师仅对OPEN/ANSWERED显式转交：NONE→QUEUED，问题状态不变，版本+1。重复排队返回原记录，不重复通知/写入。采纳或关闭将队列标记DONE；DONE不重新排队。所有OPEN/ANSWERED都在教师待办，QUEUED仅是筛选/优先标识，不要求先转交才能被教师回答。无命中或故障不自动排队。AI结果只给作者/本班教师查看，可信共享通过FAQ。

## FAQ生命周期
教师对已采纳来源预览并确认，创建PUBLISHED/version1/index=PENDING；允许来源CLOSED但保留采纳。更新需再次确认及当前版本，version+1/PENDING；旧版本立即不得用于检索引用。撤销→REVOKED/version+1/DELETE_PENDING，页面与检索立即过滤；后台删除全部旧索引后DELETED。撤销后不恢复、不允许以同来源重新发布（本组建议，待确认）。
发布唯一性按班级+原问题；重复同键返回原结果，不同键409并指向已有FAQ。保留来源问题、采纳回复、班级、确认教师、时间和版本。更新不改原回复。事实数据与待投递任务同事务；网络索引调用在事务外。可用现有任务表/单worker，不要求消息队列。建议失败后重试3次（1/5/30秒），耗尽标FAILED并允许教师重试；删除失败保持DELETE_PENDING。按FAQ+版本+动作防重，过期任务作废，迟到结果再次检查当前版本；撤销不能复活。读取FAQ引用必须复核当前发布状态，验证存储不可用则不展示该引用。

## 幂等与并发
每逻辑写入携带幂等键；作用域用户+班级+操作+资源，建议24小时保留。相同键同载荷返回原结果，不同载荷409，处理中明确提示稍后原键重试。权限先检查，成功重放优先于版本检查。超过保留期先核对已有结果再提交。所有已有资源修改原子比较版本；只有一个同版本请求成功，其他409并提示刷新，不能自动覆盖。具体header/字段由A登记，B据此编写用例。关系库失败不留下部分状态/回复/FAQ写入。

规则优先级：先授权，再重放已有幂等结果，再比较版本，最后检查新操作的状态转移。重复排队或同答案采纳若使用新键，必须提供当前版本；并发旧版本仍409。AI请求生成辅助结果，不修改问题版本；SC-COM-05仅测试会修改问题/FAQ的操作。关闭后禁止新AI请求，但作者/教师仍可读历史结果，引用展示时重新检查有效性。
