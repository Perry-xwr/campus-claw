## 怎么给地址

试用者与你在**同一台机器**上：直接开 `http://localhost:8080`。

试用者在**别的设备**上（同一 Wi-Fi / 热点）：

```powershell
# 先确认本机在这张网里的地址，不要照抄别人给的 IP
Get-NetIPAddress -AddressFamily IPv4 |
  Where-Object { $_.IPAddress -notlike '127.*' -and $_.IPAddress -notlike '169.254.*' } |
  Select-Object InterfaceAlias, IPAddress
```

然后让对方访问 `http://<上一步查到的地址>:8080`。Windows 防火墙首次会弹窗，要选**允许专用网络**。
