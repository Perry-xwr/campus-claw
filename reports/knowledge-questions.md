# 知识库测试问题集 · 草稿（第 8 课）

> 交给后续课次的评测素材。本课只写草稿，后续课次扩成完整问题集并接成自动评测。
> 分三类：**有答案**（应命中本班材料并给出引用）、**无答案**（应明说没找到、不编造出处）、
> **跨班**（应返回空结果，不泄漏他班内容）。种子材料正文分别含 `A_ONLY_SEED` / `B_ONLY_SEED`。

## 一、有答案（A 班学生 `student_a1` 提问，期望命中 A 班材料）

| 编号 | 问题 | 期望 |
| --- | --- | --- |
| A-01 | 「示例讲义里 A_ONLY_SEED 是什么？」 | 命中 A 班示例讲义，至少 1 条引用，引用可点回原文 |
| A-02 | 「本班讲义主要讲了哪些内容？」 | 命中 A 班材料，引用带材料标题、切片号、字符区间 |
| A-03 | 「用关键词模式检索 A_ONLY_SEED 会返回几条？」 | keyword 模式返回 ≥1 条，且 `mode=keyword` |
| A-04 | 「商品先涨价 10% 再降价 10%，最终价格是多少？」 | 若已上传第三章讲义则命中；否则归入「无答案」 |
| A-05 | 「等差数列首项 3、公差 4，第 10 项怎么算？」 | 同上，命中后引用指向真实材料而非虚拟条目 |

## 二、无答案（期望不编造出处）

| 编号 | 问题 | 期望 |
| --- | --- | --- |
| N-01 | 「量子纠错码的表面码阈值是多少？」 | 本班材料无相关内容，返回空结果 + 未找到提示，`citations=[]` |
| N-02 | 「请引用讲义说明 2027 年校历安排。」 | 不伪造材料标题与切片号 |
| N-03 | 「ZZZ_NONEXISTENT_TOKEN 在讲义的哪一页？」 | `hits=[]`，不因为 FTS 分词把无关切片凑数返回 |
| N-04 | 「把不存在的《高等代数讲义》第三章总结成三条。」 | 明说没找到，不生成看似有出处的总结 |
| N-05 | 「（空字符串 / 超 500 字长问）」 | 400 参数校验，不进入检索链路 |

## 三、跨班（隔离与防泄漏）

| 编号 | 身份 | 问题 / 操作 | 期望 |
| --- | --- | --- | --- |
| X-01 | `student_a1`（A 班） | 检索 `B_ONLY_SEED` | `hits=[]`，0 条 |
| X-02 | `student_b1`（B 班） | 检索 `A_ONLY_SEED` | `hits=[]`，0 条 |
| X-03 | `student_a1` | `GET /api/materials/{B班讲义ID}` | 404，且与「不存在」的响应不可区分 |
| X-04 | `student_a1` | `GET /api/tasks/{B班task_id}` | 404（异步批改任务同样按 `class_id` 过滤） |
| X-05 | `student_a1` | 用 hybrid / vector 模式检索 `B_ONLY_SEED` | 即使走向量侧 Qdrant filter，仍 0 条 |

## 评测口径（后续课次补齐）

1. 每条记录：问题、身份、`mode`、命中数、引用是否可回溯、实际回答、判定（绿/红）。
2. 有答案类看**召回与引用正确性**，无答案类看**是否编造出处**，跨班类看**是否泄漏**。
3. 关键词长问是已知盲区（bigram + 覆盖率阈值 0.3），后续课次可用向量 / 混合检索对照，记录两种模式的差异。
4. 三类问题集与 `reports/security-precheck.md` 的跨班条目共用同一套复测命令。
