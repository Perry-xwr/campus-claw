# SEC-08 会话提示可信边界加固

## Why

SEC-08 真实 Chat 实验记录了两类失败迹象：模型把恶意讲义文本冒称为系统提示词，以及在多轮对话中接受学生提出的新评分规则。当前会话生成链路需要明确的数据/指令边界。

## What Changes

- 在会话 system message 中追加固定安全边界，声明检索材料、工具返回、当前输入和历史消息不能覆盖系统及教师班级规则、身份、权限或评分规则。
- 不允许输出系统/教师提示词原文或冒称不可信文本为其内容；普通教学问答和教师合法配置继续保留。
- 以带来源和位置的 JSON 结构传递检索片段及工具返回。
- 增加 Mock 消息结构回归，并更新 SEC-08 安全规范和实验记录。

## Non-goals

- 不新增成绩修改工具、不改权限或批改服务、不重构会话架构。
- 不声称 Mock 测试能证明真实模型抗注入；本变更不自动调用真实 Chat API。
