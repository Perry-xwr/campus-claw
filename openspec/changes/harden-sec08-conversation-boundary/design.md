# 设计：SEC-08 会话可信边界

会话链路沿用现有 LangChain system/history/human 消息顺序。固定安全指令追加在教师保存的 prompt、身份、技能与引用规则之后，明确不可信内容不能重定义这些规则。教师保存的本班提示仍作为受信配置传入。

检索命中转换为包含 citation、标题、切片号、字符区间和正文的 JSON 数组；工具响应转换为 ref/text JSON 数组。二者仍处于 human 数据上下文而不进入 system message。历史用户/助手消息保留原始角色与顺序，以维持多轮能力；固定 system 边界每轮都会重新提供。

此措施是面向模型的提示约束和结构化上下文，不是硬隔离或模型行为保证。仅 Mock 检查消息构造；真实模型复测需单独授权并保留实际结果。
