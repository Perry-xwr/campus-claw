## ADDED Requirements

### Requirement: RA1 七类拆解核查清单落进 Harness 规则

审核不能整段「读一遍感觉没问题」，MUST 按七类分别核查，并把清单写进规则文件。

#### Scenario: 清单覆盖七类且可勾选

- **WHEN** 查阅 `AGENTS.md`
- **THEN** 存在接口入口、业务逻辑、数据库操作、公共函数、错误处理、安全与隐私、性能七类拆解清单
- **AND** 每类都是可勾选的具体提问，包含「参数检查与数据归属」「状态流转」「同一事务」「唯一约束还是先查一遍」「出错是否吞掉」「失败出口与信息泄漏」「循环内查询 / 索引 / 分页」

#### Scenario: 四步拆解法与并发反例

- **WHEN** 审核一段声称「保证唯一」的代码
- **THEN** 依次回答它想保证什么、实际靠什么保证、什么情况下失效、挡得住的写法
- **AND** 规则文件指出「先 `SELECT` 再 `INSERT`」在并发下会失效，正解是把规则交给数据库唯一约束并按既定语义处理冲突

#### Scenario: 本仓库红线写进规则

- **WHEN** 在本仓库生成或修改代码
- **THEN** 规则明确：身份只从服务端会话取、不信任客户端 `class_id`/`user_id`/`role`/`uploaded_by`；所有查询按 `class_id` 过滤且跨班与不存在统一 404；全仓无 `before_request`，新增视图必须显式调用 `require_*`；连续写多处放同一事务；唯一性靠 `UNIQUE`；密钥只在 `.env`；错误体统一 `{"error":{"code","message"}}`

### Requirement: RA2 七维度评审表与三分法结论

每份 AI 生成代码 MUST 按维度逐项核对并给出明确归类，不靠感觉。

#### Scenario: 评审表含七个维度

- **WHEN** 归档 `docs/AI代码审核评审表.md`
- **THEN** 评审表包含需求覆盖率、与需求的一致性、失败路径覆盖、查询性能风险、重复代码比例、漏洞风险、高风险场景七个维度
- **AND** 表头含变更/文件名、生成范围、审核人、日期、依据的规约条目

#### Scenario: 高风险场景不允许跳过

- **WHEN** 填写评审表
- **THEN** 并发、事务、数据一致性三项必须有专门核查记录，每项写清查了什么、依据哪条规约、结论是什么
- **AND** 文件明确写出「不允许跳过」的声明

#### Scenario: 三分法结论决定后续动作

- **WHEN** 给出评审结论
- **THEN** 结论只能是 `可用`（补测试、交同学评审）、`待修改`（列出具体修改项、改完重新审核）、`风险无效`（直接丢弃重写）三者之一
- **AND** 不出现「我看了，应该没问题」这类无依据结论

### Requirement: RA3 机器扫描与人工复核的固定流程

审核 MUST 固化为小组机制：机器能判的交给工具批量扫描，人只把精力用在权限、并发、事务、数据一致性这类机器判不了的高风险部分。

#### Scenario: 三层流程固定为检查步骤

- **WHEN** 一次 AI 代码变更进入评审
- **THEN** 先跑工具批量扫描（代码规范、数据库查询检查、依赖漏洞检测，整库一遍），再由人工逐行复核权限、并发、事务、数据一致性并写下依据
- **AND** 审核中发现的规则与坑回写 `AGENTS.md`，在生成阶段就拦住同类问题

#### Scenario: 扫描入口可一键执行

- **WHEN** 需要机器扫描证据
- **THEN** 可执行 `make check-security` / `make check`，输出归档到 `reports/evidence/`
- **AND** 扫描结果作为合入前的门禁证据之一

### Requirement: RA4 合入主干的准入流程

合入 `main` MUST 有对应的审核与交叉评审记录，四步准入缺一不可；未经审核的 AI 原生代码 MUST NOT 合入主干分支。

#### Scenario: 四步准入

- **WHEN** 一段 AI 生成代码准备合入 `main`
- **THEN** 必须依次完成：AI 生成初稿（注明生成范围）→ 自己逐段审核 → 交叉评审（意见留痕归档）→ 测试通过且证据归档后合入
- **AND** 审核与交叉评审记录留在 `docs/` 与 `reports/` 作为过程证据

#### Scenario: 跳过审核按违规处理

- **WHEN** 未经审核的 AI 原生代码被合入 `main`
- **THEN** 按流程违规记录，与代码缺陷同等处理
- **AND** `AGENTS.md` 明确写出「未经审核的 AI 原生代码不得合入主干分支」
